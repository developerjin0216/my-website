# 티스토리 쿠팡 리뷰 재작성본 9편

developerjin.tistory.com 의 쿠팡 리뷰를 **원래 URL에 그대로 둔 채 본문만** 새로 쓴 것입니다.
사이트로 옮기지 않았습니다. 이유는 아래 "왜 사이트가 아니라 티스토리인가"에 적었습니다.

## 적용 방법

글 하나당 5분이면 됩니다.

1. 티스토리에서 해당 글을 **수정**으로 엽니다 (새 글 아님 — URL을 지켜야 합니다)
2. 제목을 파일 맨 위 주석의 `새 제목`으로 바꿉니다
3. 에디터를 **HTML 모드**로 전환하고 본문을 파일 내용(주석 아래 전부)으로 교체합니다
4. `[사진: ...]` 자리에 원래 쓰던 사진을 다시 넣습니다 — 설명에 어떤 사진인지 적어뒀습니다
5. 저장. 발행일은 건드리지 마세요 (기존 색인을 유지해야 합니다)

사진은 수정 전에 미리 다른 탭에 띄워두고 하시면 편합니다.

## 무엇을 바꿨나

- **결론을 맨 위로.** 첫 두세 문장 안에 "누가 사면 되고 누가 사면 안 되는지"가 나옵니다.
  티스토리는 글 첫머리를 잘라 `og:description`을 만듭니다(116편 전부 `meta description`은
  블로그 전역 설명 하나를 공유하고 있어서, 실질적으로 검색 미리보기를 결정하는 건
  이쪽입니다). 결론이 위로 오면 검색 결과에 뜨는 문장이 같이 좋아집니다.
- **소제목과 짧은 문단.** 원문은 느낌표가 많고 결론이 맨 끝에 있었습니다.
- **오래된 글은 시점을 밝혔습니다.** 2022~2023년 구매 글에는 "N년 전 기준이고 지금은
  후속 모델이 나와 있을 수 있다"는 단서를 본문에 넣었습니다. 숨기는 것보다 낫습니다.
- **단점을 지우지 않았습니다.** 원문이 적은 아쉬운 점은 전부 남겼고, 일부는 오히려
  앞쪽 "이런 경우라면 사지 마세요"로 끌어올렸습니다.
- **사이트 내부 링크를 1~2개씩** 자연스러운 자리에 넣었습니다 (총 14개). 새 사이트가
  구글에 크롤될 거의 유일한 경로입니다.
- 쿠팡 링크는 **원문에 있던 주소 그대로**입니다. 새로 만들지 않았습니다. 파트너스
  고지 문구도 전부 붙어 있습니다.

## 지어낸 문장 19건을 걷어냈습니다

초안을 쓴 뒤 원문과 한 문장씩 대조하는 검증을 따로 돌렸고, **원문에 없는 내용 19건**이
걸려서 전부 삭제했습니다. 운영자 본인 후기라 안 한 말이 들어가면 그대로 거짓이 됩니다.
걸린 것들:

- "전기요금을 묻는 분이 있습니다" — 독자 문의가 있었던 것처럼 꾸며 계산기 링크를
  끼워 넣을 구실로 쓴 문장
- "매일 하던 침대 정리가 일주일에 한 번으로" — 원문은 "하루 이틀"
- "유리 조각을 치워본 입장에서는" — 원문엔 깨졌다는 말만 있음
- "음질 하나를 보고 사는 제품은 아닙니다" — 원문에 음질 언급 자체가 없음
- "노점 군고구마 수준의 단맛을 기대한다면" — 원문에 비교 대상 없음

남은 문장은 전부 원문에 근거가 있습니다.

## 왜 사이트가 아니라 티스토리인가

처음 요청은 "쿠팡 리뷰를 사이트에 게시"였는데, 확인해보니 방향이 반대였습니다.

| | developerjin.tistory.com | 8282114.xyz |
|---|---|---|
| 나이 | 4년 | 이 호스트에서 15일 |
| 색인 | 116편 | 거의 0 |
| 애드센스 | **게재 중** (ca-pub-3640943750342373, 단위 5447541257) | 사이트 추가 거절 |
| 쿠팡 파트너스 | 게재 중 | 배너만 |

색인된 자산에서 미색인 자산으로 글을 옮기는 건, 돈이 들어올 수 있는 자리에서 아직
안 되는 자리로 콘텐츠를 빼는 것입니다. 그래서 **같은 URL에 두고 내용만 좋게** 했습니다.
쌓인 색인과 나이를 유지한 채 본문만 올라갑니다.
