쿠팡 리뷰 9편 재작성본은 여기가 아니라 **블로그 작업 폴더**에 있습니다.

```
C:/Users/MEGA/Projects/blog/drafts/<슬러그>/post.md
```

처음에 HTML로 이 폴더에 만들었는데, 기존 워크플로(`/blog-post` 스킬)는
티스토리 **마크다운 모드**에 붙여넣는 `post.md` 형식을 씁니다. 형식이 달라
적용이 번거로웠던 것이라, 같은 내용을 그 파이프라인 형식으로 옮겼습니다.

적혀 있습니다. 새 글로 올리면 안 됩니다 — URL과 발행일을 지켜야 4년치 색인이
유지되고, 같은 내용으로 새 글을 만들면 기존 글과 경쟁합니다.
